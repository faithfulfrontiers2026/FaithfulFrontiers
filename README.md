# Faithful Frontiers Website Prototype

Static, Vercel-ready concept website for Faithful Frontiers.

## Included
- Premium responsive landing page
- Interactive local trip-brief generator
- Group-use-case tabs
- Full-screen workspace demo
- Dedicated Trust Center
- Faithful Frontiers logo asset
- Vercel security headers

## Run locally
Open `index.html` directly, or serve the folder with any static server.

## Deploy to Vercel
1. Unzip this project.
2. Upload/push the folder to GitHub, or import the folder through Vercel.
3. Framework preset: **Other** / static.
4. No build command is required.
5. Output directory can remain blank/root.

## Important prototype note
The Trust Center describes target security architecture and recommended controls. It intentionally does not claim completed certifications or audits.
